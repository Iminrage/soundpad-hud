# Soundpad HUD

Emote-меню в стиле Fortnite поверх Soundpad (Steam). Нажимаешь **Ctrl + Space**, на экране появляется колесо со звуками, выбираешь мышью, отпускаешь, и Soundpad проигрывает звук. Управление идёт через официальный интерфейс удалённого управления Soundpad (named pipe `\\.\pipe\sp_remote_control`, RC 1.1.2).

Windows 10/11, Node.js (LTS), Soundpad из Steam.

## Запуск

```bat
npm install
npm start
```

1. Запусти Soundpad (он должен быть открыт, пока работает HUD).
2. Запусти `npm start`. Откроется окно настроек, иконка появится в трее. Закрытие окна сворачивает приложение в трей, выход через меню иконки.
3. При первом запуске секторы автоматически заполнятся первыми звуками первой категории. Проверь кнопкой ▶ в настройках, что звук доходит до Soundpad.
4. Открой игру в оконном или borderless-режиме и нажми Ctrl + Space.

`npm run start:hidden` запускает сразу в трей. `npm run dist` собирает portable-exe (electron-builder, не проверялось).

## Как пользоваться колесом

| Действие | Что происходит |
|---|---|
| Ctrl + Space (по умолчанию) | показать колесо |
| Движение мыши | выбор сектора по направлению от центра |
| ← / → | выбор сектора с клавиатуры (запасной вариант) |
| Отпустить комбинацию (режим «держать») | сыграть выбранный звук |
| ЛКМ | подтвердить (в обоих режимах) |
| ПКМ или Esc | отмена |

В режиме «нажал, выбрал кликом, закрыл» колесо остаётся на экране, пока не будет клика или отмены.

## Окно настроек

- **Комбинация**: кнопка «Изменить» записывает новую (первая основная клавиша с модификаторами, Esc отменяет запись).
- **Режим**: «держать» или «нажал, выбрал кликом, закрыл».
- **Колесо**: 4/6/8/10/12 секторов, мёртвая зона в центре, чувствительность мыши.
- **Куда играть**: в микрофон, в наушники, или в оба (хотя бы одно всегда включено).
- **Секторы**: у каждого иконка (эмодзи), название на колесе, категория Soundpad и звук. Есть «Заполнить из категории» и кнопка ▶ для проверки.
- **Служебное**: отладочный лог и папка с конфигом.

Конфиг и лог лежат в `%APPDATA%\soundpad-hud\` (`config.json`, `hud.log`).

## Что нужно знать

- **Хоткей не блокируется.** Библиотека `uiohook-napi` только слушает клавиши. Ctrl + Space дойдёт и до игры, и до системы (на многих машинах это переключение раскладки). Если мешает, выбери другую комбинацию. Подавление клавиш потребует нативного хука, это отдельная задача.
- **Клики и стрелки тоже доходят до игры.** ЛКМ для подтверждения, ПКМ для отмены и ← → одновременно получит и игра. Основной режим «держать и отпускать» этого избегает.
- **Эксклюзивный полноэкранный режим не поддерживается**: оверлей над ним не отобразить. Работает в оконном и borderless.
- **Другие клиенты Soundpad.** Если одновременно подключены Stream Deck-плагин, веб-интерфейс и т. п., канал может быть занят. Soundpad принимает команды, пока запущен; отдельного переключателя «включить удалённое управление» в документации нет, есть только логирование RC-команд.
- **Шрифт.** Burbank проприетарный, поэтому используются системные жирные шрифты (Bahnschrift и запасные). Свой шрифт кладётся в `src/assets/fonts` и подключается в `src/overlay/overlay.css`.

## Допущения, не проверенные на реальном Soundpad и в реальном Electron

Код писался без доступа к Windows, Soundpad и сети. Логика покрыта автотестами на имитации Soundpad (unix-сокет вместо pipe), но следующее нужно проверить руками:

1. **Формат XML** ответов `GetCategories(true, false)` и `GetSoundlist()` (атрибуты `index`, `name`, `url`, `title`, `artist` у `Category` и `Sound`). Парсер толерантный, но `npm run probe` покажет реальные ответы, и тестовые образцы в `test/helpers.js` стоит привести к ним.
2. **API uiohook-napi**: события `keydown`, `keyup`, `mousemove`, `mousedown`, поля `keycode`, `ctrlKey`/`altKey`/`shiftKey`/`metaKey`, `button` (1 — левая, 2 — правая), имена `UiohookKey.Ctrl`, `CtrlRight`, `Meta` и т. д. Сверить с `node_modules/uiohook-napi`.
3. **Мышь в играх.** Выбор сектора копит смещения мыши между событиями. Если игра захватывает курсор и каждый кадр возвращает его в центр, смещения могут гаситься. Тогда колесо выбирается стрелками ← →, а подход нужно доработать (например, через Raw Input).
4. **Оверлей поверх игры**: прозрачное окно без фокуса на уровне `screen-saver`. В borderless должно работать, но зависит от игры и античита.
5. **Pipe-клиент на Windows**: логика проверена на unix-сокете, настоящий named pipe Soundpad не проверялся.
6. Сборка `npm run dist` и версии зависимостей (в `package.json` стоит `latest`; после первой установки их стоит закрепить).

## Дорожная карта

Запланировано, но намеренно не сделано в v1:

1. **Страницы звуков внутри категории**: колесо мыши листает страницы по N секторов.
2. **Пагинация по категориям** для сложных сценариев: переключение категорий прямо на колесе.
3. Автозапуск с Windows, профили под разные игры, иконки категорий (`GetCategories(…, true)`).

Сейчас секторы хранятся плоским списком (`slots` в `config.json`). Для страниц понадобится миграция конфига (поле `version` для этого заведено) и показ индикатора страницы в центре колеса. Подробности в `CLAUDE.md`.

## Структура

```
src/main/        главный процесс: main.js, soundpad.js (pipe), library.js, hotkey.js,
                 selection.js, config.js, xml.js, logger.js
src/preload/     мосты IPC для окон
src/overlay/     колесо (SVG), CSS в стиле Fortnite
src/settings/    окно настроек
scripts/         probe-soundpad.js (диагностика), make-icon.py (иконка)
test/            автотесты (node:test)
```

## Тесты и диагностика

```bat
npm test          # автотесты: pipe-клиент, парсер, хоткей, выбор сектора, конфиг, сквозной сценарий main
npm run probe     # сырые ответы живого Soundpad
```

Если колесо не открывается: проверь комбинацию в настройках и включи «Писать команды Soundpad в лог», затем смотри `hud.log`. Если звук не играет: кнопка ▶ в настройках покажет ответ Soundpad (`R-200` успех, `R-404` команда не найдена).
