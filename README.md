# Soundpad HUD

Колесо звуков в стиле emote-меню Fortnite поверх игр для [Soundpad](https://store.steampowered.com/app/629520/Soundpad/). Зажимаешь бинд — появляется колесо, наводишь мышью на звук, отпускаешь — Soundpad играет его в микрофон и/или в наушники.

Приложение управляет Soundpad через его официальный интерфейс удалённого управления (named pipe `\\.\pipe\sp_remote_control`, Remote Control 1.1.2). В процесс игры ничего не внедряется, ввод не подделывается.

Windows 10/11, Soundpad из Steam (проверено на 4.0.35).

## Возможности

- **Колесо звуков** (по умолчанию **Ctrl + Alt**): свои звуки на 3, 5, 7, 9 или 11 секторов или целая категория Soundpad по страницам, страницы листаются колесом мыши.
- **Колесо категорий** (по умолчанию **Ctrl + Shift**): сначала все категории Soundpad, клик открывает категорию. Первая папка «⭐ Частые» — звуки, которые ты чаще всего играешь из колёс.
- **«Стоп»** всегда в нижнем секторе. В колесе категорий, пока ничего не играет, там стрелка «Назад».
- **Прослушивание**: зажатая ПКМ на звуке играет его только тебе в наушники, пока держишь.
- **Подсказки**: под колесом совет и что сейчас сделают клики, отпускание бинда и прокрутка. Над колесом полное название выбранного звука.
- **Мышь не уходит в игру**: пока колесо открыто, оно забирает фокус и захватывает курсор, как при Alt + Tab. Камера не крутится, клик не стреляет, после закрытия игра снова активна. Можно выключить.
- Бинды из любых клавиш или только из модификаторов, режимы «держать бинд» и «нажать бинд», сброс каждого раздела настроек к значениям по умолчанию.

## Управление в колесе

| Что сделать | Как |
|---|---|
| Выбрать сектор | мышь (направление от центра) или ← → |
| Сыграть звук | отпустить бинд или ЛКМ на звуке |
| Прослушать в наушниках | держать ПКМ на звуке |
| Открыть категорию / вернуться | ЛКМ на категории / ЛКМ на «Назад» или ПКМ в центре |
| Листать страницы | прокрутка |
| Закрыть без звука | Esc, ЛКМ в центре, ПКМ в центре (если назад некуда) |

По умолчанию колесо не закрывается, если отпустить бинд мимо звука: можно отпустить клавиши и спокойно выбирать мышью.

## Установка

**Готовая сборка.** Скачай `Soundpad HUD <версия>.exe` из [Releases](https://github.com/Iminrage/soundpad-hud/releases) и запусти. Установка не нужна, при запуске exe распаковывается во временную папку. Сборка без цифровой подписи, поэтому Windows SmartScreen может показать «Неизвестный издатель»: «Подробнее» → «Выполнить в любом случае».

**Из исходников** (нужен Node.js LTS):

```bat
npm install
npm start
```

1. Запусти Soundpad: он должен быть открыт, пока работает HUD.
2. Откроется окно настроек, иконка появится в трее. Закрытие окна прячет приложение в трей, выход через меню иконки.
3. При первом запуске колесо звуков заполнится первыми звуками первой категории. Кнопка ▶ в настройках проверит, что звук доходит до Soundpad.
4. Открой игру в оконном режиме или в окне без рамки и зажми бинд.

`npm run start:hidden` запускает сразу в трей.

## Что нужно знать

- **Бинд не перехватывается**: нажатия доходят и до игры, и до Windows. Ctrl + Shift и Alt + Shift в Windows часто переключают раскладку — если мешает, смени бинд или отключи это сочетание в параметрах Windows.
- **Эксклюзивный полноэкранный режим** не поддерживается: поверх него окно не показать, а при потере фокуса такая игра сворачивается. Работает в оконном режиме и в окне без рамки.
- **Игры, запущенные от администратора**: обычная программа не видит клавиши, пока такая игра на переднем плане. Запусти HUD тоже от администратора.
- **Античиты**: HUD не трогает процесс игры и не подделывает ввод, но строгие античиты (Vanguard, FACEIT) непредсказуемы — используй на свой риск.

Настройки, лог и счёт «Частых» лежат в `%APPDATA%\soundpad-hud\` (`config.json`, `hud.log`, `stats.json`).

## Разработка

```bat
npm test          # автотесты (node:test): pipe-клиент на имитации Soundpad, парсер, хоткеи, конфиг, сквозной сценарий main
npm run probe     # сырые ответы живого Soundpad (Soundpad должен быть запущен)
npm run dist      # portable exe в dist\ (electron-builder)
```

```
src/main/        главный процесс: main.js, soundpad.js (pipe), library.js, hotkey.js,
                 selection.js, config.js, stats.js, xml.js, logger.js
src/preload/     мосты IPC для окон
src/overlay/     колесо (SVG) и подсказки
src/settings/    окно настроек
scripts/         probe-soundpad.js (диагностика), make-icon.py (иконка)
test/            автотесты
```

Устройство и принятые решения подробно описаны в [CLAUDE.md](CLAUDE.md).

Если колесо не открывается, проверь бинд в настройках, включи «Писать команды Soundpad в лог» и посмотри `hud.log`. Если звук не играет, кнопка ▶ в настройках покажет ответ Soundpad (`R-200` — успех).
